A mark that says read, not healthy.

The leaf went with the old name. Revely is about revealing what a label actually says, so the mark should come from the scanning system — the reticle, the seal, the bilingual rule — not from the wellness shelf. The mark below is built from shapes already in the design system.

Decided: the Aperture. The export set is built and sitting in assets/revely/.

03

Splash

Camera-first means the splash must not be a moment — it's a held frame while the camera warms, typically 200–600ms. So it is deliberately almost nothing: ground, mark, wordmark. No tagline, no illustration, no progress spinner.

It also does one clever thing: the splash ground is the same ink as the viewfinder's darkest corner, so the transition into the live camera reads as the room lighting up rather than a screen swap.

Splash rules
01Mark is 96px, optically centred — sits 6% above true centre so it doesn't look low.
02Never show a spinner. If the camera takes longer than 1.2s, fade in the mono line "warming the lens" at the bottom.
03Native launch screen must be static — the bracket draw-on is a JS layer that only plays on cold start, and only if the camera isn't ready yet.
04Exit is a 220ms cross-fade to the live viewfinder. No zoom, no slide.
05No tagline in the centre stack. "READ THE LABEL" sits at the bottom edge as a mono footer and is optional.

Non-negotiables
01The icon is never green, amber or red. Those three inks mean a verdict and nothing else — an icon that's green implies every scan passed.
02No gradient, no gloss, no inner shadow on the ground. Flat ink.
03Android adaptive foreground gets the mark at 60% — the outer 40% is the platform's mask allowance and will be cropped by circular launchers.
04Rename the package, the deep-link scheme and Brand.name in the same pass — a half-renamed app leaks "Auraly" into share sheets and permission dialogs.
05Flatten alpha before submitting. The supplied PNGs are fully opaque but still carry an RGBA channel, which App Store validation rejects on the 1024² icon. Expo prebuild normally strips it; if you submit a bare archive, run pngcrush -c 2 on icon.png, icon-dark.png and icon-tinted.png first. The transparent ones — icon-fg, splash-mark — must keep their alpha.
06icon-dark.png is intentionally identical to icon.png — the icon is already ink-ground, so there is nothing for dark mode to change. It ships as a separate file only because iOS 18 expects the slot to be filled.
