AURALY MONETIZATION — FUNCTIONAL REQUIREMENTS
1. Subscription System (Auraly+)
Implement a new paid subscription tier called Auraly+.
Behavior
A user with an active Auraly+ subscription automatically receives:


Unlimited scans (but scans should still be rate-limited to prevent abuse: max 20 scans per hour).


Full ingredient explanations (detailed “Learn More” content).


Full scan history access (no limits).


Personalization features (allergen selection, ingredient flags, etc.).


Free tier users do not get the above.


Billing
Subscription price: $4.99/month.


Implement billing via Stripe.


Store the subscription status in the database (status, timestamps, etc)


Support webhooks for renewal, cancellation, failed payment, etc.


Internal Free Subscriptions
Add an admin-only interface or API function allowing me (the owner) to assign a free Auraly+ subscription to any user.


This should bypass billing entirely.


Include:


Admin input: user email


Output: user becomes an active subscriber instantly



2. Scan Limitations for Free Users
Implement a monthly quota for free-tier users.
Free Users
Maximum 5 scans per month.


Show a persistent counter in the UI (e.g., “3 of 5 free scans remaining”).


When the user reaches 5 scans:


Block further scans.


Display upgrade modal with:


“Upgrade to Auraly+”


“Purchase scan pack”


“Cancel”


Automatically reset counts every month.

3. Scan Packs for Non-Subscribers
Users may purchase additional scans without subscribing.
Scan Pack Options
20 scans → $2.99


50 scans → $4.99


120 scans → $9.99


Behavior
Purchased scan pack scans accumulate into extraScansAvailable.


When a free-tier user scans:


Use monthly free scans first.


If exhausted, consume from extraScansAvailable.


If both are 0 → block and show paywall.

Only deduct a scan when a scan analysis is completed successfully. Any errors or timeouts upon scanning should not deduct a scan from the user.


UI Behavior
After a scan, show remaining balance.


In settings or billing page, show:


Free-tier monthly remaining scans


Remaining paid scan pack scans


Button to purchase more
