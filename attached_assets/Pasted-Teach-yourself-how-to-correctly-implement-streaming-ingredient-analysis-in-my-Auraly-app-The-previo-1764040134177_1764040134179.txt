Key Principles You Must Understand Before Coding
1. GPT-5.1 CAN stream, but only within a single request
GPT cannot stream a list of ingredients one-by-one in a single call.
It streams text chunks, not parallel items.
Therefore:
✔ You MUST make 
one GPT call per ingredient
✔ You MUST stream the results yourself from the backend
✔ You MUST NOT batch ingredients into one GPT request
This is non-negotiable.

2. The backend must use Server-Sent Events (SSE)
SSE is the only approach that works reliably in:
Replit


Browsers


React


Next.js


The backend must set these headers:
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive
X-Accel-Buffering: no
All four are required. Missing any of them breaks streaming.

3. The Replit proxy WILL buffer output unless disabled
Most of your generated apps on Replit failed because:
responses were buffered


flush() was not called


wrong headers were used


you ended the request too early


the request didn’t stay open


To fix this, you must:
Immediately flush headers


Write each ingredient result as its own SSE event


Never wait for all ingredients to finish


Never use Promise.all


Keep the connection open until the final “done” event



4. The frontend MUST use EventSource
fetch() CANNOT be used for SSE streaming in this context.
You must use:
const es = new EventSource(`/stream-ingredient-analysis`, { withCredentials: false });
The frontend must listen for events:
ingredientResult


ingredientError


done


You MUST NOT attempt to buffer or wait; render each result as soon as it arrives.

5. Caching must be checked per ingredient BEFORE the GPT call
Behavior:
If ingredient cached → stream immediately


If expired or missing → analyze with GPT


After GPT finishes → update cache and stream


Keep going without waiting for any other ingredient
