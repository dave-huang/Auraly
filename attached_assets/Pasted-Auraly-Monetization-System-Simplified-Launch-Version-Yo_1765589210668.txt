Auraly Monetization System — Simplified Launch Version
You are updating the Auraly web app to support a streamlined monetization system optimized for launch and user validation.
Implement the following functional requirements using the existing architecture and codebase. Choose the best approach for database updates, API routes, and integrations while maintaining the current system's structure and patterns.

CORE MONETIZATION MODEL
Free Tier

5 scans per month (resets on the 1st of each month)
Basic ingredient analysis only (no personalized flags applied)
No scan history access
User can view/edit their personalization preferences in settings, but preferences are not applied to scan results

Premium Tier (Auraly+)

Price: $4.99/month
Unlimited scans (with abuse prevention: max 20 scans per hour)
Full personalized ingredient analysis (allergen flags, preference-based highlights are applied)
Full scan history access with search
Detailed "Learn More" content for ingredients

7-Day Free Trial

All new users automatically start with a 7-day Premium trial (no credit card required)
During trial: full access to all Premium features including personalization
After trial expires: user automatically converts to Free tier (5 scans/month) unless they subscribe
User's personalization preferences remain saved but are not applied to scan results until they subscribe

SUMMARY OF CHANGES
This simplified model:

Two tiers only: Free (5/month) vs Premium ($4.99/month)
7-day trial for all new users (no credit card)
Onboarding with personalization during trial
Preferences saved but not applied for free users post-trial
No scan packs (removed for simplicity)
No referral system (can add later)
Clean data for measuring trial → paid conversion

Key user flows:

Sign up → Trial → Onboarding → Use Premium features → Trial expires → Convert to Free or Subscribe
Free user scans → Hits quota → Sees paywall → Subscribes or waits for reset
Premium user scans → No limits (except 20/hour) → Sees personalized results
